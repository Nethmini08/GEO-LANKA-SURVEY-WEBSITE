# GEO LANKA SURVEY - Official Website

This project is a clean, responsive landing page designed for a surveying service provider. It was developed to showcase core services and provide contact information for clients in the surveying industry.

## Overview
The website serves as a digital portfolio/presence for "Geo Lanka Survey," focusing on professionalism and ease of user navigation. It highlights the technical services provided and ensures a smooth user experience.

## Tech Stack
- Languages: HTML5, CSS3
- Design:Responsive Web Design principles
- Deployment: GitHub Pages

## Key Features
- Professional Landing Page: Designed with a focus on business-oriented aesthetics.
- Service Highlights: Clearly lists the surveying services offered.
- Mobile Responsive: Works seamlessly on different screen sizes (desktops, tablets, and mobile devices).

## Project Structure
- `index.html`: The main structure of the website.
- `styles/`: Contains the CSS files for styling and layout.
- `assets/`: Contains images and icons used throughout the site.
